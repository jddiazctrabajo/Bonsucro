# Sistema de Trazabilidad de Aplicaciones

Aplicación para la gestión y auditoría de aplicaciones de fertilizantes y herbicidas.

## Objetivos

- Importar formatos de diferentes productores.
- Homologar la información.
- Validar inconsistencias.
- Generar indicadores.
- Facilitar auditorías de sostenibilidad.

## Tecnologías

- Python
- Streamlit
- Pandas
